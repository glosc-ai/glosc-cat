# 说猫语

说猫语 是一款面向养猫用户的猫语互动应用，目标是把“听不懂猫咪在说什么”和“想主动和猫咪互动却不知道怎么做”这两件事，变成简单、轻松、可爱的日常体验。

产品围绕两个核心能力展开：
- 猫语转人话：分析猫咪叫声的音色、频率、节奏和时长，输出情绪、需求和可理解的人类语言描述。
- 人话转猫语：把用户输入的内容转化为更贴近猫咪交流风格的声音表达，提升互动趣味性。

## 产品愿景
- 让用户更懂自己的猫，而不是只得到一个冷冰冰的识别结果。
- 把宠物沟通做成有陪伴感的产品，而不是单纯的工具页。
- 通过可爱、柔和、治愈的 UI 风格，建立更强的情感连接与分享欲。

## 目标用户
- 18-35 岁的养猫用户，尤其是注重生活方式与情绪价值的年轻女性用户。
- 愿意记录宠物日常、喜欢可爱视觉风格、关注互动体验的养宠人群。
- 对“猫咪是不是饿了、生气了、想撒娇了”这类问题有强需求的用户。

## 核心功能
### 1. 猫语识别
- 录制猫咪叫声或导入音频。
- 提取叫声中的频率、时长、节奏等特征。
- 输出识别结果，包括情绪状态、潜在需求和通俗解释。

### 2. 人话转猫语
- 输入一句人类语言，例如“过来吃饭啦”或“我陪你玩”。
- 选择语气或情绪标签，例如温柔、安抚、召唤、兴奋。
- 生成更具猫咪交流感的声音并支持播放。

### 3. 情绪与需求分析
- 识别快乐、紧张、不耐烦、撒娇、求关注等常见情绪倾向。
- 识别饥饿、想陪伴、想玩耍、环境不适等常见需求信号。
- 提供简洁的照护建议，帮助用户理解下一步该怎么做。

### 4. 友好且有记忆点的界面体验
- 首页突出录音、识别、翻译三个核心动作。
- 结果页以卡片化方式呈现情绪、需求、解释、建议，降低阅读压力。
- 全局 UI 风格贴近“养宠女孩”审美，强调柔和、可爱、轻松与陪伴感。

## UI 风格方向
- 关键词：可爱、治愈、软糯、陪伴感、精致感。
- 推荐配色：奶油白、蜜桃粉、燕麦杏、浅棕、鼠尾草绿。
- 组件风格：大圆角、轻阴影、柔和渐变、插画感图形、清晰层级。
- 交互气质：少打扰、强反馈、易理解，避免过度复杂或“专业仪器化”的视觉表达。

## MVP 建议范围
- 猫语录音与识别。
- 人话输入与猫语播放。
- 情绪与需求结果展示。
- 可爱的首页与结果页视觉体系。

## 当前项目状态
- 已完成 MVP 主界面，首页整合了“猫语转人话”和“人话转猫语”两个核心闭环。
- 已完成猫语识别流程，支持麦克风录音、导入本地音频、启发式情绪判断、需求解释和行动建议。
- 已升级猫语识别流程，会先把录音与内置真实猫叫样本做本地特征比对，再输出更贴近样本语义的情绪、需求和建议。
- 已完成人话转猫语流程，支持文本输入、语气模板、猫语生成，并直接播放匹配到的真实猫叫音频。
- 已完成轻量记录能力，最近互动记录会通过 SwiftData 持久化保存。
- 已完成常用短语收藏能力，可保存高频的人话转猫语内容。
- 已完成基础分享能力，当前支持分享文本结果与猫语内容。
- 已接入内置猫叫样本库，可直接试听和一键分析公开样本资源。

## 当前实现说明
- 当前版本的猫语识别会优先提取录音的时长、响度、停顿、节奏起伏等特征，并与本地真实猫叫样本逐个比较；若相似度不够高，再回退到启发式判断，不承诺专业诊断级准确性。
- 当前版本的人话转猫语会在生成结果时同步匹配最贴近语义和语气的真实猫叫样本，并直接播放该音频，不再把系统语音朗读作为主路径。
- 当前资源库已优先接入 mp3 和 wav 样本做试听与分析；仓库中的 ogg 素材会在后续统一转码后继续开放。
- UI 已按照“养宠女孩”风格完成第一版视觉落地，包括奶油白、蜜桃粉、燕麦杏、鼠尾草绿等低饱和配色，大圆角卡片与柔和阴影。

## 已完成功能
- 首页品牌区、双主入口、状态提示、最近互动、收藏短语、互动小贴士。
- 猫语转人话：录音、导入音频、内置猫叫样本试听、内置样本分析、结果卡片、建议动作、再次尝试。
- 猫语转人话：录音、导入音频、内置猫叫样本试听、内置样本分析、基于本地真实样本相似度的语义解释、结果卡片、建议动作、再次尝试。
- 人话转猫语：文本输入、语气模板、生成猫语、直接播放对应猫叫音频、收藏短语。
- 数据持久化：互动记录、收藏短语。
- 测试：4 个单元测试和 2 个 UI 测试已通过。

## 待迭代功能
- 可分享的视觉结果卡片模板，目前分享内容以文本为主。
- 更细粒度的音频特征分析与模型化判断，当前已完成本地样本比对，后续可继续补充更丰富的频谱特征与个体化样本库。
- 统一转码并接入 ogg 样本，减少当前资源格式差异。
