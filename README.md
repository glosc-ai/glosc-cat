# 说猫语

说猫语 是一款面向养猫用户的猫语互动应用，目标是把“听不懂猫咪在说什么”和“想主动和猫咪互动却不知道怎么做”这两件事，变成简单、轻松、可爱的日常体验。

产品围绕两个核心能力展开：
- 猫语转人话：分析猫咪叫声的音色、频率、节奏和时长，输出情绪、需求和可理解的人类语言描述。
- 人话转猫语：把用户输入的内容转化为更贴近猫咪交流风格的声音表达，提升互动趣味性。

## 产品愿景
- 让用户更懂自己的猫，而不是只得到一个冷冰冰的识别结果。
- 把宠物沟通做成有陪伴感的产品，而不是单纯的工具页。
- 通过可爱、柔和、治愈的 UI 风格，建立更强的情感连接与分享欲。

## 目标用户
- 18-35 岁的养猫用户，尤其是注重生活方式与情绪价值的年轻女性用户。
- 愿意记录宠物日常、喜欢可爱视觉风格、关注互动体验的养宠人群。
- 对“猫咪是不是饿了、生气了、想撒娇了”这类问题有强需求的用户。

## 核心功能
### 1. 猫语识别
- 录制猫咪叫声或导入音频。
- 提取叫声中的频率、时长、节奏等特征。
- 输出识别结果，包括情绪状态、潜在需求和通俗解释。

### 2. 人话转猫语
- 输入一句人类语言，例如“过来吃饭啦”或“我陪你玩”。
- 选择语气或情绪标签，例如温柔、安抚、召唤、兴奋。
- 生成更具猫咪交流感的声音并支持播放。

### 3. 情绪与需求分析
- 识别快乐、紧张、不耐烦、撒娇、求关注等常见情绪倾向。
- 识别饥饿、想陪伴、想玩耍、环境不适等常见需求信号。
- 提供简洁的照护建议，帮助用户理解下一步该怎么做。

### 4. 友好且有记忆点的界面体验
- 首页突出录音、识别、翻译三个核心动作。
- 结果页以卡片化方式呈现情绪、需求、解释、建议，降低阅读压力。
- 全局 UI 风格贴近“养宠女孩”审美，强调柔和、可爱、轻松与陪伴感。

## UI 风格方向
- 关键词：可爱、治愈、软糯、陪伴感、精致感。
- 推荐配色：奶油白、蜜桃粉、燕麦杏、浅棕、鼠尾草绿。
- 组件风格：大圆角、轻阴影、柔和渐变、插画感图形、清晰层级。
- 交互气质：少打扰、强反馈、易理解，避免过度复杂或“专业仪器化”的视觉表达。

## MVP 建议范围
- 猫语录音与识别。
- 人话输入与猫语播放。
- 情绪与需求结果展示。
- 可爱的首页与结果页视觉体系。
