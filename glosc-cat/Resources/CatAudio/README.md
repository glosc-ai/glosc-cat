# CatAudio 资源说明

本目录现只保留相对更干净、更适合 MVP 试听与分类演示的猫叫样本。

## 当前保留样本

| 文件名 | 语义标签 | 描述 | 来源 | 许可 |
| --- | --- | --- | --- | --- |
| `clean_meow_mixkit.mp3` | 基础喵叫 | 简短、清晰的基础 meow | Mixkit: `Sweet kitty meow` | Mixkit License |
| `hungry_meow_mixkit.mp3` | 饥饿喵叫 | 更贴近想吃东西的短叫声 | Mixkit: `Domestic cat hungry meow` | Mixkit License |
| `attention_meow_mixkit.mp3` | 求关注 | 更贴近求关注/招呼的短叫声 | Mixkit: `Little cat attention meow` | Mixkit License |
| `distressed_meow_mixkit.mp3` | 难受/委屈 | 偏不适、偏求助的短叫声 | Mixkit: `Little cat pain meow` | Mixkit License |
| `begging_meow_mixkit.mp3` | 央求/撒娇 | 偏撒娇、偏请求的短叫声 | Mixkit: `Cartoon kitty begging meow` | Mixkit License |
| `clean_purr_whiskers.ogg` | 干净呼噜 | 已去除爆音并裁掉尾部 meow 的呼噜声 | Wikimedia Commons: `File:Whiskers' purr edit.ogg` | Public Domain |

## 取舍说明

- 已移除旧的一批环境杂音较重、音色不够稳定或不够干净的样本。
- 当前保留的几条 `Mixkit` 音频更适合先做分类演示、播放页和结果页样本。
- `begging_meow_mixkit.mp3` 带一点风格化处理，比旧素材干净，但真实性略弱，可作为过渡样本。
- `clean_purr_whiskers.ogg` 是目前保留的呼噜声样本里最干净的一条。

## 使用建议

- 第一批推荐直接用于应用内演示：`clean_meow_mixkit.mp3`、`hungry_meow_mixkit.mp3`、`attention_meow_mixkit.mp3`、`clean_purr_whiskers.ogg`。
- 如果需要更真实的情绪类样本，可把 `distressed_meow_mixkit.mp3` 作为“难受/求助”分类占位。
- 如果后续上架或正式分发，使用 `Mixkit` 素材前仍需再次核对其最新许可条款。
- 若后续接入 iOS 播放资源，建议再统一转码到 `m4a` 或 `caf`。

## 备注

- 这批资源更偏“干净、短促、便于交互演示”，并不是严格标注的数据集。
- 社交平台视频中的猫叫虽然更生活化，但复用授权通常不清晰，因此这次没有作为正式资源保留。
