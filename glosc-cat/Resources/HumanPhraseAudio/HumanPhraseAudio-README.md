# HumanPhraseAudio 资源说明

本目录收集“人话转猫语”里更常用的短语音频映射，优先用当前已筛过、较干净的猫叫样本做语义占位。

## 说明

- 这些音频不是严格意义上的“逐字翻译”，而是更贴近该短语语气和互动意图的猫叫映射。
- 当前先覆盖了常见高频短语：吃饭、饿了、玩耍、真棒、过来、走开、喜欢。
- 如果后续要扩展“不要怕”“不可以”“快回来”“别咬”“睡觉啦”等短语，可继续沿用这套映射思路补齐。
